#  Snake Game (Python & Streamlit)

A classic **Snake Game** built using **Python** and **Streamlit**. The game features smooth movement, score tracking, random food generation, screen wrapping, and proper error handling.

##  Features

- Classic snake gameplay  
- Keyboard controls (Arrow keys)  
- Random food generation  
- Live score display  
- Screen wrapping (snake reappears from opposite side)  
- Self-collision detection (game over)  
- Restart or quit option after losing  
- Exception handling for stability  


##  Technologies Used

- **Python 3**
- Streamlit


##  Installation

1. Install Python 3.8 or above.
2. Run "streamlit run app.py"
